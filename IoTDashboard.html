วางลิงก์รูปตรง หรืออัปโหลดไฟล์ด้านล่างแทนก็ได้ — ถ้ามีค่าตรงนี้จะใช้แทนธีมสี
ไฟล์จะถูกเก็บใน Supabase Storage ของโปรเจกต์คุณ (ดูขั้นตอนเปิดใช้ที่ SETUP_GUIDE.md)
ถ้ารูปพื้นหลังโทนสว่าง ตัวอักษรสีขาวจะอ่านยาก — ปรับเป็นสีเข้มแทนได้ที่นี่
ลบแล้วกู้คืนไม่ได้ ข้อมูลการ์ดและการตั้งค่าทั้งหมดของโปรเจกต์นี้จะหายไป
ใช้ Read API Key เท่านั้น หาได้จากหน้า Channel ของคุณใน thingspeak.com > API Keys
คนที่มีลิงก์จะเห็นค่าที่วัดได้แบบเรียลไทม์แบบอ่านอย่างเดียว แก้ไขอะไรไม่ได้ ปิดสวิตช์นี้เมื่อไรก็ปิดการเข้าถึงทันที
ต้องอัปโหลดไฟล์ public_view.html ไว้ในโฟลเดอร์เดียวกับ index.html บนโฮสต์ของคุณด้วย
ตั้งช่วงค่าปกติ (ต่ำสุด/สูงสุด) ของแต่ละฟิลด์ได้ในแท็บ "การ์ด/ฟิลด์" ระบบฝั่งเซิร์ฟเวอร์จะเช็คทุก ~10 นาที และเว้นการแจ้งเตือนซ้ำอย่างน้อย 30 นาทีต่อฟิลด์ — ฟีเจอร์นี้ต้องตั้งค่า Edge Function เพิ่มตาม SETUP_GUIDE.md ก่อนถึงจะทำงานจริง

📋 ข้อตกลงการใช้งาน

กรุณาอ่านและยอมรับข้อตกลงก่อนสมัครสมาชิก

(ข้อความฉบับนี้เป็นฉบับร่างชั่วคราว เจ้าของเว็บไซต์จะปรับปรุงเนื้อหาข้อตกลงฉบับเต็มในภายหลัง)

ยินดีต้อนรับสู่ IoT Dashboard การสมัครสมาชิกและใช้งานระบบนี้ถือว่าคุณรับทราบและยอมรับเงื่อนไขต่อไปนี้:

1. ข้อมูลที่คุณกรอก (เช่น ThingSpeak Channel ID, API Key) จะถูกเก็บไว้ในบัญชีของคุณเพื่อใช้แสดงผลแดชบอร์ดเท่านั้น

2. คุณเป็นผู้รับผิดชอบต่อความถูกต้องและความปลอดภัยของข้อมูลที่นำเข้าสู่ระบบด้วยตนเอง

3. หากเปิดใช้งานฟีเจอร์แชร์แบบสาธารณะ คุณรับทราบว่าผู้อื่นที่มีลิงก์จะสามารถเข้าถึงข้อมูลที่แสดงในหน้านั้นได้

4. ผู้ให้บริการขอสงวนสิทธิ์ในการปรับปรุง แก้ไข หรือระงับการให้บริการได้ตามความเหมาะสม
